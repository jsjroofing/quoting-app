📤 Export prices.json
Central prices live in prices.json on GitHub — both apps read it. This button builds the complete file from this device's current prices
Monthly price update: tap Copy prices.json, then paste over the contents of prices.json in the quoting-app repo on GitHub and commit to main. Netlify deploys automatically and both apps pick up the new prices on next open. Includes this device's rate overrides and item prices; unpriced items export as null.

Every device moves onto the central prices automatically the first time it opens the app online after prices.json has real prices in it — no need to visit each phone. Use central prices is the manual version of the same thing: it clears every price override stored on this device (labour/GC/admin/harness rates and all item prices), including any set deliberately since.
✨ AI Polish
Connects the "Polish with AI" button on every report to Claude via a secure proxy server
Never put an API key directly in this app — it would be visible to anyone using it. Have your developer deploy a small proxy server that holds the key securely, then paste its URL here. The "Polish with AI" button on every report will use this same URL.
